# Flight Log Tracker

## Description
A simple web application designed to help student pilots track flight information and total flight hours.

## Features
- Add flight entries
- Store flight data in browser local storage
- Delete entries
- Automatically calculate total hours
- Track:
  - Aircraft type
  - Aircraft identification
  - Departure airport
  - Arrival airport
  - Remarks
  - Flight hours

## Technologies Used
- HTML
- CSS
- JavaScript
- GitHub Pages

## How to Use
1. Enter flight information
2. Click "Add Flight"
3. View saved entries in the table
4. Delete entries if needed
